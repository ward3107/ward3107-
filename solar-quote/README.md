# Solar Quote

מחשבון הצעות מחיר ותחזית כלכלית למערכות סולאריות, בעברית (RTL). הגרסה הזו היא בנייה מחדש של המחשבון הסטטי המקורי ב־Next.js ו־TypeScript.

## מה יש בו

- **מודל פיננסי** (`src/lib/finance.ts`): ייצור והתיישנות פאנלים, מכירת חשמל לרשת, **צריכה עצמית**, שינוי שנתי בתעריפים ובתחזוקה, החלפת ממיר, החזר השקעה פשוט ומהוון, **NPV**, **IRR**, **LCOE**, CO₂ שנחסך וניתוח רגישות לתפוקה (‎±10%).
- **הצעה ללקוח**: שער, מחיר מפורט, היקף, מפרט ואחריות, תנאי תשלום, גרפים, טבלת תחזית, הנחות יסוד, בלוק חתימה. הדפסה או שמירה כ־PDF מהדפדפן (A4).
- **הצעות שמורות** בדפדפן, שכפול, מחיקה, גיבוי וייבוא JSON. פרטי העסק והלוגו נשמרים להצעה הבאה.
- **קישור שיתוף** בלי שרת: ההצעה מקודדת ב־hash של הכתובת (לא נשלחת לשרת), ללא תמונות.
- תמונות (לוגו, הדמיה) מכווצות אוטומטית לפני שמירה.
- מצב כהה, מובייל, נגישות (תוויות, `aria-live`, ניווט מקלדת), PWA עם עבודה offline.

## הרצה

```bash
npm install
npm run dev        # http://localhost:3000
npm run check      # typecheck + lint + tests + build
```

האתר הוא סטטי לגמרי (`output: 'export'`), והבנייה נוצרת בתיקיית `out/`.

## פריסה ל־GitHub Pages

הפריסה מוגדרת ב־`.github/workflows/pages.yml`: בכל push ל־`main` שנוגע ב־`solar-quote/` נבנה האתר עם `NEXT_PUBLIC_BASE_PATH=/<שם הריפו>/solar-quote` ומתפרסם. ב־PR רץ רק שלב הבנייה, בלי פריסה.

הגדרה חד־פעמית: בריפו, **Settings → Pages → Build and deployment → Source: GitHub Actions**.

הכתובת אחרי הפריסה הראשונה: `https://ward3107.github.io/ward3107-/solar-quote/`

לפריסה בשרת אחר (Vercel, Netlify) אפשר להשתמש ב־`npm run build` ובתיקיית `out/`. בתת־נתיב יש להגדיר `NEXT_PUBLIC_BASE_PATH`.

## תאימות לגרסה הישנה

כשהפרמטרים החדשים כבויים (צריכה עצמית 0, ללא שינויים שנתיים וללא החלפת ממיר) המודל משחזר את המספרים של המחשבון המקורי. `tests/finance.test.ts` בודק זאת מול ערכי הזהב של `example.json`.

שינוי אחד מכוון: המחיר מחושב **בשקלים שלמים** והשורות תמיד מסתכמות (מחיר מערכת פחות הנחה = לפני מע״מ, ועוד מע״מ = סה״כ). בגרסה הישנה המחיר בכרטיס (69,208) ובתוכנית העסקית (69,209) הוצגו בשני ערכים שונים.

## מבנה

```
src/lib        לוגיקה טהורה: finance, validation, sanitize, share, storage, image, format
src/components טופס, תוצאות, גרפי SVG, מסמך ההצעה
src/app        דפים: / (עריכה), /proposal, /quotes
tests          בדיקות Vitest
public/sw.js   service worker
```

## הערות

- הנתונים נשמרים ב־`localStorage` של הדפדפן בלבד. אין בקצה שרת או חשבונות.
- מקדם הפליטה (0.4 ק״ג/קוט״ש) ושיעור ההיוון (4%) הם הערכות ברירת מחדל שניתן לעדכן בהנחות המתקדמות.
- התחזית אינה התחייבות לתוצאות. המסמך כולל הערה בנוסח זה.
